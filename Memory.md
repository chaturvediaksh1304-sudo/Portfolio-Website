# Memory

Running record of what this repo is and how it got here. Hand-written notes live
above the history marker; the commit table below it is generated.

## What this is

A portfolio built as a macOS desktop. Apps open as draggable windows, the dock
holds projects and social links, and the desktop carries a profile card, three
world clocks, and a scrolling skills marquee. React + TypeScript + Vite, Tailwind
via CDN, Framer Motion for animation, Zustand for window state.

## Where things live

| Concern | File |
| --- | --- |
| Dock roster — every app, its icon and kind | `apps/registry.ts` |
| Project copy, experience, education, references | `constants.tsx` |
| Desktop shell — wallpaper, profile card, marquee, dock | `desktop/DesktopView.tsx` |
| Menu bar, Control Center, Spotlight, windows | `desktop/` |
| App icons | `public/app-icons/` |

Adding a project app means two edits: a `PROJECTS` entry in `constants.tsx` and an
`APPS` entry in `apps/registry.ts` that finds it by title substring. The dock,
mobile grid, and Spotlight all read `APPS`, so one entry covers all three.

## Decisions worth remembering

- **Project windows** embed the live site in an iframe when a project has an
  `external` URL, otherwise they fall back to the repo's GitHub OG card. The
  fallback has no second fallback, so a private repo shows a broken image.
- **The skills marquee** scrolls a fixed distance per cycle, so its `duration`
  has to grow with the list — a longer list at the old duration scrolls faster.
- **Brightness** in Control Center drives a full-screen black overlay in
  `App.tsx`. The level is stored on that element, not in React state, because
  Control Center unmounts when closed. It floors at 70% so the site stays visible.
- **Icons** are bitmaps exported from `assets/Applications Icons/`, except
  `volt.svg`. Source artwork lives in that assets folder; `public/app-icons/`
  holds the copies the app actually serves.
- **Typechecking** is clean — `npx tsc --noEmit` reports no errors. Keep it that
  way; Vite uses esbuild and never typechecks, so tsc is the only thing that
  catches these. `@types/react` and `@types/react-dom` were missing at first,
  which made TS reject `key` on every component.

## Known gaps

- The repo carries 54 tracked iCloud duplicate files (`* 2.tsx`, `* 2.ts`,
  `* 2.png`). Nothing imports them; they are excluded from the typecheck but
  still ship in the repo and should probably be deleted.
- Running `npm run dev` from the iCloud-synced directory is unreliable: Vite
  reports ready but then stalls serving modules.
